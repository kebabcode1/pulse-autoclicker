Frequently Asked Questions

How do I install Pulse AutoClicker? +

Download the official release PulseAutoClicker_v1.0.zip package. Extract it and run PulseAutoClicker_Setup.exe to install, or launch pulse_autoclicker.exe directly!

What if Windows Smart App Control blocks the zip file? +

Because the app is built from fresh open-source binaries, right-click PulseAutoClicker_v1.0.zip → select Properties → check Unblock at the bottom → click Apply. You can also run Unblock-File -Path .\PulseAutoClicker_v1.0.zip in PowerShell.

How does Frame Sync work? +

Frame Sync queries your primary display adapter's refresh rate via Win32 EnumDisplaySettingsW (e.g. 144Hz or 240Hz) and caps click intervals to align perfectly with your monitor's display frames.

Where are presets and license keys stored? +

All settings, presets (presets.json), license keys (license.lic), lifetime statistics (stats.json), and wallpapers are stored safely in %APPDATA%\PulseAutoClicker.
