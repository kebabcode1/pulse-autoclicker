Frequently Asked Questions

Everything you need to know about installation, security, and usage.

Does Pulse AutoClicker work when minimized or unfocused? +
Yes! Pulse AutoClicker uses a background Windows event thread (GetAsyncKeyState) that detects key and mouse presses system-wide even when you are focused on a game or application.
What should I do if Windows SmartScreen or Chrome blocks the download? +
Because Pulse AutoClicker is a newly published independent application that simulates hardware input calls (SendInput), security scanners may show a warning:

• Windows SmartScreen: Click More Info -> Run Anyway.
• Google Chrome: Go to Downloads (Ctrl + J) -> Click Keep dangerous file -> Keep anyway.
How do I uninstall Pulse AutoClicker? +
Pulse AutoClicker includes a native uninstaller (pulseuninstaller.exe) integrated into Windows Control Panel. Simply go to Windows Settings -> Apps -> Installed Apps -> Pulse AutoClicker -> Uninstall.
