# ⚡ Pulse AutoClicker

**Pulse AutoClicker** is a modern, high-precision desktop autoclicker for Windows. Built for performance and reliability, it offers sub-millisecond click timing, global system-wide hotkey support (keyboard and mouse clicks), customizable duty cycles, and preset configuration management.

---

## ✨ Key Features

- **⚡ High-Precision Engine**: Powered by low-latency Windows API click execution (`SendInput`) and microsecond precision timing (`timeBeginPeriod`).
- **🎯 2-Decimal Precision**: Fine-tune Clicks Per Second (up to `500.00 CPS`) and Click Duty Cycle (`0.01 %` to `99.99 %`).
- **🕹️ Dual Trigger Modes**:
  - **Toggle Mode**: Press your hotkey once to start clicking; press again to stop.
  - **Hold Mode**: Auto-clicks while holding down your activation key or mouse button; stops instantly upon release.
- **🌐 Global Unfocused Hotkeys**: Key and mouse button monitoring works system-wide across all applications and games, even when Pulse AutoClicker is running in the background. Supports interactive binding for keyboard keys and mouse buttons (Left, Right, Middle, Side X1/X2 buttons).
- **💾 Preset System**: Save, load, and manage custom click configurations for different games or tasks.
- **🔒 HWID Key Protection**: Secure license key authorization locked to your computer's Hardware ID for seamless login.

## 🚀 Getting Started

### 1. Download & Installation
1. Go to the [Releases](https://github.com/kebabcode1/pulse-autoclicker/releases/tag/main) page and download **`PulseAutoClicker_v1.0.zip`** (or **`PulseAutoClicker_Setup.exe`**).
2. Extract the `.zip` archive to any folder on your computer.
3. Run **`PulseAutoClicker_Setup.exe`** to install the application and create desktop shortcuts.

---

## 🔑 Access Key Activation Guide

Pulse AutoClicker uses Hardware ID (HWID) license key protection:

1. **Launch the App**: Open Pulse AutoClicker. On the login screen, your unique **System HWID** (e.g., `HWID-XXXX-XXXX...`) will be displayed.
2. **Copy HWID**: Click **`📋 Copy HWID`** and send it to your administrator/seller to receive your access key.
3. **Activate**: Enter your access key (`PA-XXXX-XXXX-XX`) into the key field and click **Activate**.
4. **Auto-Login**: Once activated, Pulse AutoClicker automatically logs in every time you launch the application.

## 🛡️ Windows Defender & Security Notice

Because Pulse AutoClicker simulates low-level mouse inputs and listens for global hotkeys across Windows, security scanners or Windows SmartScreen may occasionally display a warning for newly downloaded binaries:

- **Windows SmartScreen**: Click **More Info** -> **Run Anyway**.
- **Google Chrome Block**: Go to Downloads (`Ctrl + J`) -> Click **Keep dangerous file** -> **Keep anyway**.
